# How to use

``` bash
PYTHONPATH=src python -m tanuki.mori.print_labo.<module>                    # combined (default)
PYTHONPATH=src python -m tanuki.mori.print_labo.<module> --mode individual  # one file per part
PYTHONPATH=src python -m tanuki.mori.print_labo.<module> --output path      # custom output
```
