# Blender Stencil Generator

## Overview

Blender Stencil Generator is an experimental Blender add-on for transforming images into artistic stencil layers, halftones, and fabrication-ready vector patterns.

The project focuses on keeping the entire workflow inside Blender whenever possible, allowing designers, artists, makers, and printmakers to generate custom stencils directly from images.

The add-on aims to bridge digital image processing, procedural pattern generation, and physical fabrication.

## Goals

- Convert images into stencil-ready artwork.
- Generate CMYK separation layers.
- Create artistic halftone and pattern-based representations.
- Produce fabrication-ready geometry.
- Maintain a Blender-native workflow.
- Support experimentation with non-traditional printing patterns.

## Workflow

1. Image
1. Color Separation
1. Pattern Generation
1. Stencil Optimization
1. Geometry Creation
1. Export / Fabrication

The project is not intended to be just another halftone generator.

- Sine-wave rendering
- Honeycomb rendering
- Circuit-inspired rendering
